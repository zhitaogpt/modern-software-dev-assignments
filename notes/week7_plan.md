# 第 7 周计划：AI 代码审查与智能体驱动开发

## 核心目标
1.  **智能体驱动开发 (Agent-Driven Development)**：练习使用“一次性提示词 (1-shot prompting)”在单次迭代中实现功能和测试。
2.  **AI 代码审查 (Graphite)**：体验并评估 AI 生成的代码审查反馈。
3.  **Git/PR 工作流**：严格遵守特性分支管理（每个任务一个分支），以便进行清晰的审查。
4.  **后端增强**：扩展 FastAPI/SQLAlchemy，包含验证、复杂逻辑、模型关系和更好的测试。

## 任务分解（源自 `week7/docs/TASKS.md`）
*   **任务 1：增加端点与验证**：实现完善的 Pydantic 验证和错误处理。
*   **任务 2：扩展提取逻辑**：改进从笔记中识别行动项（Action Items）的正则表达式/逻辑。
*   **任务 3：新模型与关系**：添加新实体（例如：`Category` 或 `Tag`）并与现有模型关联。
*   **任务 4：改进测试**：侧重于分页和排序的测试覆盖率。

## 执行计划

### 阶段 1：准备与基准测试（已完成）
1.  **环境检查**：运行现有测试（`week7`）确保基准通过。
2.  **代码审查**：简要浏览 `models.py` 和 `schemas.py` 以了解当前结构。

### 阶段 2：迭代开发（任务 1-4 重复执行）
对于每个任务，我们将遵循严格的循环流程：
1.  **明确范围与分支**：
    *   定义具体的实现细节（因为任务描述较笼统）。
    *   创建新分支（例如：`feat/task-1-validation`）。
2.  **一次性实现 (1-Shot Implementation)**：
    *   构建详细的提示词。
    *   Gemini（智能体）一次性生成代码和测试。
3.  **人工审查（关键步骤）**：
    *   在运行/修复**之前**检查代码。
    *   记录发现的问题（人工审查笔记），用于后续的 writeup。
    *   应用修复。
4.  **验证**：
    *   运行测试。
    *   提交 (Commit) 并推送 (Push)。
5.  **Graphite 审查（异步）**：
    *   用户在 Graphite/GitHub 上打开 PR。
    *   等待 Graphite Diamond 的评论。
    *   在 `writeup.md` 中对比 Graphite 的反馈与人工反馈。

### 阶段 3：总结与提交
1.  **编写 Writeup**：汇总 PR 链接、审查对比和反思。
2.  **最终润色**：确保 `writeup.md` 符合所有评分标准。
