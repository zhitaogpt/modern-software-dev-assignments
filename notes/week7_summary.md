# 第 7 周总结：智能体开发与代码审查

## 核心学习目标
1.  **智能体驱动开发 (Agent-Driven Development)**：成功应用“单次提示词 (1-Shot Prompting)”技术，在单次迭代中实现复杂的全栈功能（后端逻辑 + 数据库模型 + 自动化测试）。
2.  **AI 代码审查**：通过将更改划分为逻辑清晰、可验证的单元，为 Graphite Diamond 审查做好了准备。
3.  **高级后端模式**：
    *   **Pydantic V2**：将 Schema 升级到 `ConfigDict` 并使用了 `Field(default_factory=list)` 等最佳实践。
    *   **SQLAlchemy 模型关系**：使用关联表实现了 `Note` 与 `Tag` 之间的多对多 (Many-to-Many) 关系。
    *   **健壮性测试**：为分页、排序和正则表达式提取等边缘情况创建了专门的测试套件。

## 技术实现亮点
-   **任务 1 (验证)**：强制执行标题长度约束，并添加了 `is_starred` 加星切换功能。
-   **任务 2 (正则)**：构建了复杂的正则表达式引擎用于行动项提取，支持 Markdown 任务列表 (`- [ ]`) 和多种关键字。
-   **任务 3 (标签)**：设计了简洁的标签管理方案，优雅地处理了标签的自动创建和去重。
-   **任务 4 (质量保证)**：通过批量测试套件验证了分页和排序在各种参数下的准确性。

## 关键自动化
-   **结构化规划**：利用 `notes/week7_plan.md` 驱动智能体的执行上下文。
-   **自动验证**：智能体在每次重大代码更改后自动执行 `make test`，立即捕获并修复了诸如“可变默认参数”和“正则边界条件”等漏洞。
